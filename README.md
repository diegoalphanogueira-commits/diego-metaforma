# Diego Metaforma

Central profissional estática, responsiva e sem dependências de build. Três caminhos: Korax, presença local e Diagnóstico PACT interativo.

## Publicação

GitHub Pages: branch `main`, pasta `/ (root)`. Não há domínio personalizado configurado nesta etapa.

## Foto e domínio (próxima etapa)

1. Adicione uma foto autorizada em `assets/diego-nogueira.webp` e configure `SITE_CONFIG.photo` em `script.js`. Até lá, o site usa um monograma DN, sem simular uma foto.
2. Quando conectar `DiegoMetaforma.com.br`, atualize o canonical e `og:url` no HTML e o campo `SITE_CONFIG.canonical`. Configure o domínio no GitHub Pages e o DNS antes de usar esse endereço.
3. Os destinos e o WhatsApp estão no HTML; o CTA do resultado é montado no JS. Número usado: contato já publicado no site Korax.

## Diagnóstico

8 perguntas, 2 por pilar PACT. Cada resposta vale 0, 1 ou 2 pontos. Cada pilar é convertido em escala 0–100; o total é a média dos quatro pilares. A recomendação prioriza a menor pontuação (em empates, a ordem PACT). É uma autoavaliação orientativa, não avaliação por IA nem promessa de resultados. Respostas só em memória da página, sem banco, cookies ou coleta automática. Só são enviadas pelo próprio visitante se ele escolher continuar no WhatsApp.

Animações respeitam `prefers-reduced-motion`. O conteúdo principal permanece acessível sem JavaScript; o quiz requer JavaScript.
